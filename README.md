# CafeMenu B

Учебное Android-приложение и страница распространения для лабораторной работы 6.

## Сборка

- Самостоятельный проект Java Activity + SQLite + локальный WebView; не экспорт Adalo.
- Пакет ru.cafemenu.lab.release, версия 1.1, Android 8.0+, target API 35.
- Готовый APK находится в downloads; рядом опубликована SHA-256.
- Ключ подписи, пароли, исходные пользовательские данные и ответы участников не входят в этот репозиторий.
- Сборка не запрашивает runtime-разрешений и доступа к интернету.

## Изображения

В версии 1.1 в APK и шапке приложения используется точная иконка B из опроса — меню с приборами. B установлена по запросу автора, а не по результатам опроса. Исходные SVG и PNG 512×512 сохранены в media. Снимки экрана являются реальными снимками браузерного предпросмотра общего WebView-интерфейса. Они не доказывают установку и запуск APK на физическом телефоне. Фото: Unsplash, ссылки в PHOTO_SOURCES.csv.

## Данные и ограничения

Учебные аккаунты, избранное и оценки хранятся локально на устройстве, без облачной синхронизации, писем и восстановления пароля. Первый аккаунт — администратор. Используйте отдельный учебный пароль. Удаление приложения удаляет данные.

## Незавершённые испытания

Пользователь сообщил об успешной проверке версии 1.0 на Xiaomi Redmi Note 12 Pro с Android 13. Нужны подтверждение установки обновления 1.1, реальные снимки устройства, отзывы 2–3 тестировщиков и минимум 10 ответов для сравнения иконок.

Версия 1.1 имеет versionCode 2 и прежние пакет и ключ подписи. Обновление рассчитано на установку поверх 1.0 с сохранением данных. Не удаляйте старое приложение перед установкой обновления.
