# CafeMenu B

Учебное Android-приложение и страница распространения для лабораторной работы 6.

## Сборка

- Самостоятельный проект Java Activity + SQLite + локальный WebView; не экспорт Adalo.
- Пакет ru.cafemenu.lab.release, версия 1.0, Android 8.0+, target API 35.
- Готовый APK находится в downloads; рядом опубликована SHA-256.
- Ключ подписи, пароли, исходные пользовательские данные и ответы участников не входят в этот репозиторий.
- Сборка не запрашивает runtime-разрешений и доступа к интернету.

## Изображения

Иконка A повторяет фактическую иконку APK. B — альтернативный вариант для опроса, а не подтверждённый победитель. Исходные SVG и PNG 512×512 сохранены в media. Снимки экрана являются реальными снимками браузерного предпросмотра общего WebView-интерфейса. Они не доказывают установку и запуск APK на физическом телефоне. Фото: Unsplash, ссылки в PHOTO_SOURCES.csv.

## Данные и ограничения

Учебные аккаунты, избранное и оценки хранятся локально на устройстве, без облачной синхронизации, писем и восстановления пароля. Первый аккаунт — администратор. Используйте отдельный учебный пароль. Удаление приложения удаляет данные.

## Незавершённые испытания

Нужны установка и проверка на реальных устройствах, отзывы 2–3 тестировщиков и минимум 10 реальных ответов для сравнения иконок. Результаты этих этапов не подставлены и не объявлены выполненными.
